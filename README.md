# Calculator with History Management | Python

A console-based calculator application built in Python that performs fundamental arithmetic operations while incorporating file handling to save, view, and manage calculation history.

## 🚀 Features
- **Core Arithmetic Operations:** Performs addition, subtraction, multiplication, and division.
- **History Management:** Automatically saves past calculations to a text file and allows users to view or clear stored records.
- **Robust Error Handling:** Manages invalid user inputs and prevents runtime crashes from division-by-zero errors.
- **Interactive Console Interface:** Clean menu-driven navigation for seamless user interaction.

## 🛠️ Tech Stack & Concepts
- **Language:** Python
- **Core Concepts:** Functions, Control Flow, String Manipulation, File Handling (Read/Write Operations), Error Handling (`try-except`).
